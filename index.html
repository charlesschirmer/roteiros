GitHub Gist — Sincronização
Como configurar:
1. Acesse github.com/settings/tokens → Generate new token (classic)
2. Marque apenas o escopo gist e gere o token
3. Acesse gist.github.com → crie um Gist secreto com qualquer arquivo
4. Copie o ID do Gist (os ~32 caracteres na URL) e cole abaixo
5. Clique em Salvar e Sincronizar
